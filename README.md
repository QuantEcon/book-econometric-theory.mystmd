# A Primer in Econometric Theory: web edition (working draft)

**Read it at <https://quantecon.github.io/book-econometric-theory.mystmd/>.**

This is a free working draft of John Stachurski, *A Primer in Econometric
Theory*. The final version is published by
[MIT Press](https://mitpress.mit.edu/9780262034906/a-primer-in-econometric-theory/)
(2016). A PDF of the draft is linked from every page of the site.

Found an error? Please [open an issue](../../issues).

## About this repository

The pages are **generated**. They are converted from the book's LaTeX source,
which is kept in a separate repository, with
[claude-latex-to-myst](https://github.com/QuantEcon/claude-latex-to-myst), and
built with [MyST](https://mystmd.org) (QuantEcon's fork). Every publish
replaces the content here, so edits made directly in this repository are lost;
corrections go into the LaTeX source.

The site is deployed by `.github/workflows/deploy.yml` on every push to `main`.
